Financial inclusion and mobile-money adoption: a survey-based analysis

What household-level factors are associated with the transition from financial exclusion to regular use of formal and mobile-money services?

Mayo T. N. KadangaPublished [DATE TO CONFIRM]Modified [DATE TO CONFIRM]
⚑ Article body not yet translated — showing English. [TRANSLATION REQUIRED]
Abstract

Using nationally-representative survey data, we combine Multiple Correspondence Analysis with logistic regression to identify drivers of financial inclusion. We report marginal effects as actionable policy levers and provide a fully reproducible R + Quarto pipeline. [CONTENT TO CONFIRM]

1 · Model specification

We model the probability that household i is financially included as a logistic function of agent access, distance to the nearest branch, and a set of socio-economic controls:

logit(pi) = β0 + β1·accessi + β2·distancei + Xᵢγ + εi

2 · Reproducible estimation

The full model is estimated in R; every figure in this article is generated from the code below.

inclusion-model.R 
# fit logistic inclusion model
model <- glm(included ~ access + distance + educ + income,
             data = hh, family = binomial)
# marginal effect of agent access
margins(model, variables = "access")
